# 📊 Smart Analytics Tool

## 📌 Project Overview

Smart Analytics Tool is an interactive data analysis application built using Streamlit, Pandas, and Plotly.

The tool allows users to upload any CSV dataset and instantly perform data exploration, statistical analysis, missing value detection, and interactive visualizations without writing code.

This project was developed as part of the Data Science Internship Week 2 Mini Hackathon.

---

## 🚀 Features

### ✅ CSV Upload

* Upload any CSV dataset for analysis.

### ✅ Dataset Preview

* View the first few rows of the uploaded dataset.

### ✅ Dataset Shape

* Display the total number of rows and columns.

### ✅ Missing Value Analysis

* Identify missing values in each column.

### ✅ Statistical Summary

* Generate descriptive statistics for numerical columns.

### ✅ Interactive Visualizations

* Histogram
* Box Plot
* Scatter Plot

### ✅ User-Friendly Dashboard

* Attractive UI
* Sidebar navigation
* Interactive charts
* Responsive layout

## ▶️ How to Run the Project

### Step 1: Clone Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Step 2: Open Project Folder

```bash
cd smart-analytics-tool
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run Streamlit Application

```bash
streamlit run app.py
```
